# E-commerce Business Performance Analysis (SQL)

## Project Overview
This project analyzes sales, product performance, and customer data for "TheLook" e-commerce platform using **Google BigQuery**. 

## Business Questions Answered
1. **What is our monthly revenue trend?** (Identified growth patterns and seasonality).
2. **What are the top 5 product categories per country?** (Helps inventory management target localized demand).

## Tech Stack & Skills Demonstrated
* **Dialect:** Google Standard SQL (BigQuery)
* **Advanced Skills:** Common Table Expressions (CTEs), Window Functions (`DENSE_RANK`), Data Aggregation, Multi-table `JOIN` operations.
